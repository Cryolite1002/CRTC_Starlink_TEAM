# 启程： 
开始学习。黄作为大核，学习电控知识，上网学习装置的用法等。冷开始学习fusion360建模软件。 同时开始考虑如何设计收集小球的方案： 1.像推土机一样铲起球，同时安装一个漏斗收集 2.联想到乒乓球捡球器，原理利用皮筋弹性，将球压入容器且不会掉落 3.像蟹钳一样夹入车内 ......

迈步： 国庆，开始正式的组装。 The goal：让车动起来

## Date 10/09

设计阶段 反复模拟决定将电池盒还有马达放在底盘下方，上方留给电机驱动板，单片机，舵机，PS2接收器等部件（此时并没有考虑收集装置的设计）

实操 先布局好电池盒，接着确定马达位置，然后在上方找合适的孔位安装电机驱动板，单片机，PS2接收器，接着就是给马达焊接电线。小车已经可以操纵运动了！！ （此时马达是用热熔胶固定）

Accident1: PS2和接收器很难连接，于是到交创找坤哥，发现是群里一个发的文件版本太旧了导致的 由于排线太乱，使用面包板接线，可接线后出了问题，用电压表测半天最后确认是面包板内部断路了（折腾半天。。）

##PS2接收器在牛顿力学的作用下崩了（安装位置不合适导致），只能用剩下的那个接收器了 **然后由于马达是热熔胶固定的，怕测试不通过只能买上螺丝的套了

我们买了L型接收器，还有马达套，等快递

## Date 10/12

设计收集装置：

排除方案1 因为感觉摩擦力太小，铲不起来，收集又需要一个镂空的空间。怎么设计都不合适 排除方案3 因为收集效率太低

确定方案2 利用收集乒乓球装置的原理。

实操 给盒子打孔用来穿线，孔间距约1cm。 使用雪糕棒做机械臂，两端分别固定舵机和盒子。通过舵机旋转让盒子从高处拍地面，进而让小球通过弹力绳进入盒内 最后我们成功让这辆车自由移动并收集小球

## Date 10/13
